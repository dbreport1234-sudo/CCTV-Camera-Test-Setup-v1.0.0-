# CCTV Camera Test & Setup (v1.0.0)

โปรแกรม Windows สำหรับช่าง ใช้เช็ค/ตั้งค่ากล้อง IP โดยเฉพาะ **กล้องรุ่นเก่าที่เปิดผ่านหน้าเว็บไม่ได้**
กรอกแค่ **IP / ชื่อผู้ใช้ / รหัสผ่าน / เลือก Main หรือ Sub** — ระบบหายี่ห้อและ RTSP URL ให้เอง

## หลักการ (ทำไมกล้องเก่าถึงเปิดได้)
กล้องเก่ามักมีหน้าเว็บที่ต้องใช้ ActiveX/Plugin ซึ่งเบราว์เซอร์ยุคนี้เปิดไม่ได้
โปรแกรมนี้ไม่ใช้หน้าเว็บของกล้อง แต่ดึงภาพผ่าน **RTSP** แล้วให้ **ffmpeg** แปลงเป็นภาพที่หน้าต่างโปรแกรมเล่นได้
(รองรับ H.264 / H.265 / MJPEG และเสียง G.711 / AAC ที่เบราว์เซอร์ปกติเล่นตรง ๆ ไม่ได้)

## ติดตั้ง (ทำครั้งเดียวต่อเครื่อง)
1. ติดตั้ง **Node.js LTS** (v18 ขึ้นไป) จาก https://nodejs.org/
2. แตก zip ไปไว้ที่ที่เขียนไฟล์ได้ เช่น `C:\CCTV-Tech`
3. ดับเบิลคลิก **`setup.bat`** (ต้องต่ออินเทอร์เน็ตตอนติดตั้ง ใช้เวลาสักครู่)
4. เปิดโปรแกรมด้วย **`run-app.bat`**

> ติดตั้งเสร็จแล้วใช้งานในวงแลนได้โดยไม่ต้องใช้อินเทอร์เน็ต

## วิธีใช้ (สำหรับช่าง)
1. ใส่ **IP** (หรือกดปุ่มเรดาร์ข้าง IP เพื่อสแกนหากล้องในวงแลน แล้วกด “ใช้ IP นี้”)
2. ใส่ **ชื่อผู้ใช้ / รหัสผ่าน** ตามปกติ
3. เลือก **Main Stream** หรือ **Sub Stream**
4. กด **เชื่อมต่อกล้อง** — ระบบตรวจยี่ห้อ + หา RTSP เอง (ดูความคืบหน้าที่ช่อง “สถานะการทำงาน”)
5. ใช้งาน: ปุ่มเสียง, จับภาพนิ่ง, บันทึกวิดีโอ, เต็มจอ, ซูมดิจิทัล (ล้อเมาส์), PTZ ด้านขวา
6. กด **เพิ่มกล้อง** เพื่อบันทึกเข้ารายการ — ครั้งต่อไปคลิกชื่อกล้องเดียวเชื่อมต่อได้ทันที

ไฟล์ที่บันทึกอยู่ที่ `เอกสาร\CCTV\Snapshot` และ `เอกสาร\CCTV\Record` (เปลี่ยนได้ที่แท็บ “ตั้งค่ากล้อง”)

## ระบบหา RTSP อัตโนมัติทำงานอย่างไร
1. ตรวจพอร์ตที่เปิดอยู่ (RTSP 554/8554/10554, HTTP 80/8080/8000/8899/2020)
2. ระบุยี่ห้อ/รุ่น จาก ONVIF และ API เฉพาะยี่ห้อ (Dahua, Hikvision, Uniview, Axis, Hanwha ฯลฯ)
3. ถาม ONVIF เพื่อขอ RTSP URL จริงของ Main/Sub (แก้ปัญหานาฬิกากล้องเพี้ยนให้เอง)
4. ถ้า ONVIF ไม่ได้ ลองรูปแบบ path ของ **30+ แบบ** (ยี่ห้อที่ตรวจพบลองก่อน) ด้วย RTSP DESCRIBE จริง จนเจอที่ใช้ได้
5. ถ้ารหัสผ่านผิด ระบบหยุดทันที (ไม่ลองซ้ำหลายครั้ง เพื่อไม่ให้กล้องล็อกบัญชี)

ยี่ห้อที่มีแม่แบบ: Dahua/Amcrest/Imou, Hikvision/HiLook/EZVIZ, Uniview, TP-Link/Tapo, Reolink, Axis, Hanwha/Samsung,
Vivotek, Foscam, Xiongmai (XM/กล้องจีนทั่วไป), Longse/Provision, Bosch, Panasonic และรูปแบบทั่วไปอีกหลายแบบ
ถ้ายังหาไม่เจอ ใส่ RTSP URL เองได้ที่ “ตัวเลือกเพิ่มเติม”

## PTZ
- ควบคุมผ่าน **Dahua (ptz.cgi)**, **Hikvision (ISAPI)** หรือ **ONVIF** — เลือกอัตโนมัติตามยี่ห้อ (เปลี่ยนเองได้ที่แท็บ “การตั้งค่า PTZ”)
- กดค้างที่ลูกศร/Zoom/Focus/Iris เพื่อทำงาน ปล่อยเพื่อหยุด (หยุดอัตโนมัติถ้าค้างเกิน 10 วินาที)
- Focus/Iris ใช้ได้กับ Dahua และ Hikvision (ONVIF รองรับเฉพาะ Focus ในกล้องที่มี Imaging service)
- “ตั้งค่าตำแหน่ง” จะ **เขียนทับ Preset ในกล้อง** — โปรแกรมถามยืนยันก่อนทุกครั้ง

## สร้างไฟล์ .exe เดียวแจกช่าง
ดับเบิลคลิก **`build-exe.bat`** (ต้อง setup แล้ว) ได้ไฟล์ `release\CCTV-Camera-Test-Setup-1.0.0.exe`
คัดลอกไฟล์เดียวไปเครื่องช่างได้เลย โดยไม่ต้องติดตั้ง Node.js ในเครื่องปลายทาง

## แก้ปัญหา
| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ติดต่อ IP ไม่ได้ | ตรวจ IP/สายแลน และให้เครื่องช่างอยู่วงเดียวกับกล้อง (เช่น 192.168.1.x) |
| ไม่พบพอร์ต RTSP | เข้าเมนูกล้อง/NVR เปิด RTSP (หรือ ONVIF) หรือใส่พอร์ตใน “ตัวเลือกเพิ่มเติม” |
| รหัสผ่านไม่ถูกต้อง | กรอกให้ถูกก่อนลองใหม่ — กรอกผิดบ่อยกล้องอาจล็อกบัญชีชั่วคราว |
| ได้ภาพแต่กระตุก | ใช้ Sub Stream หรือไปแท็บตั้งค่าเปลี่ยนการส่งข้อมูลเป็น TCP |
| ไม่มีเสียง | กล้องอาจปิดไมค์ไว้ — ถ้ากล้องไม่ส่งเสียงมา โปรแกรมจะแจ้ง |
| “ผู้ดูเต็ม / Not Enough Bandwidth” | กล้องรุ่นเก่ารับได้แค่ 1-2 การเชื่อมต่อ ปิดโปรแกรมอื่นที่ดูกล้องตัวนี้อยู่ (ตอนบันทึกวิดีโอจะใช้อีก 1 การเชื่อมต่อ) |
| ดาวน์โหลด ffmpeg ไม่ได้ตอนติดตั้ง | แอนตี้ไวรัส/ไฟร์วอลล์บล็อก — อนุญาตแล้วรัน setup.bat ใหม่ |

## ข้อจำกัด / ความปลอดภัย
- **ไมค์พูดคุย 2 ทาง (Talk) ยังไม่รองรับ** (ฟังเสียงจากกล้องได้อย่างเดียว)
- รหัสผ่านที่กด “เพิ่มกล้อง” เก็บในไฟล์ `cameras.json` ในเครื่องนี้ **แบบไม่เข้ารหัส** — ใช้กับเครื่องช่างส่วนตัว และอย่าแชร์ไฟล์นี้
- เซิร์ฟเวอร์ภายในฟังที่ `127.0.0.1` เท่านั้น (เครื่องอื่นในวงแลนเข้าไม่ได้)
- สแกนวงแลนอาจทำให้ Windows Firewall ถามสิทธิ์ (UDP ONVIF Discovery) — เลือกอนุญาตในเครือข่ายส่วนตัว
- ใช้กับกล้องที่คุณมีสิทธิ์ดูแลเท่านั้น
